Interactive 3D visualizer for the TUMTraf-V2X dataset.

This project helps explore infrastructure LiDAR point clouds, camera images, 3D object boxes, and LiDAR-camera projection geometry in one browser-based viewer.

Key features:

- 3D LiDAR point cloud visualization
- Infrastructure camera frustums
- 3D object box selection
- LiDAR-to-camera projection overlays
- Multi-camera ray visualization
- Image-to-3D object selection
- Calibration perturbation demo
